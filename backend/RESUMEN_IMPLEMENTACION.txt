==============================================================================
RESUMEN DE IMPLEMENTACION - DOMIPEDIDOSX BACKEND
==============================================================================

Proyecto: Django + Django REST Framework
Usuario personalizado: apps.usuarios.User (AUTH_USER_MODEL = "usuarios.User")
Login por email, PK UUID, campo "rol": cliente / operador / cocina /
repartidor / admin.

Arquitectura respetada:
- Vistas delgadas (views.py)
- Logica de negocio en services.py
- Validacion en serializers.py
- Permisos reutilizables en apps/core/permissions.py
- Respuestas y mensajes en espanol

No se modificaron modelos ni se crearon migraciones.
No se agregaron dependencias distintas a djangorestframework-simplejwt
(ya existente, ahora con version fija).

==============================================================================
FUNCIONALIDADES IMPLEMENTADAS
==============================================================================

HU 1 - Registro de cliente
- POST /api/usuarios/registro/
- Normaliza el email (minusculas y sin espacios).
- Valida unicidad del email sin distinguir mayusculas.
- Valida la contrasena con los validadores de Django.
- Corrige el mensaje "coenciden" -> "coinciden".
- Ignora campos sensibles enviados por el cliente (rol, is_staff, is_active,
  is_superuser); el usuario siempre queda como cliente.
- No devuelve tokens.

HU 2 - Autenticacion JWT
- POST /api/auth/login/    -> access + refresh
- POST /api/auth/refresh/  -> nuevo access
- GET  /api/usuarios/me/   -> datos del usuario autenticado
- Access token: 15 minutos.
- Refresh token: 7 dias.
- Header: Authorization: Bearer <access>
- USER_ID_FIELD = "id" (PK UUID).
- Login normaliza el email antes de autenticar.
- Usuarios inactivos no pueden iniciar sesion.
- Credenciales invalidas devuelven 401 con mensaje generico.
- Claim "rol" incluido como informacion para el cliente, NO para permisos.

HU 3 - Permisos por rol
- Permisos reutilizables en apps/core/permissions.py.
- Exigen usuario autenticado y activo.
- Deciden con request.user.rol (BD), nunca con el claim del token.
- Sin token valido: 401.
- Token valido sin rol permitido: 403 con mensaje en espanol.
- Admin no tiene acceso implicito.
- Combinables con el operador | de DRF.

HU 4 - Registro de personal operativo y administradores (por admin)
- POST /api/usuarios/personal/
- Solo un usuario con rol admin puede usarlo (EsAdmin).
- Roles permitidos: operador, cocina, repartidor y admin.
- Operador, cocina y repartidor requieren al menos una sede activa; se crean
  los registros en SedeUsuario.
- Un admin adicional se crea con is_staff=True.
- Si el rol es repartidor se crea automaticamente PerfilRepartidor con
  disponible=False.
- Responde 201 con los datos del usuario, su rol y las sedes vinculadas.
- Errores: 400 por datos/sedes invalidas, 403 si no es admin, 401 sin token.

Cambios realizados en la HU 4:
- services.py: constantes ROLES_PERSONAL y ROLES_OPERATIVOS, y funcion
  crear_usuario_personal(...) con transaction.atomic(), validacion de rol,

HU 5 - Recuperacion de contrasena desde el correo registrado
- POST /api/usuarios/password-reset/           (AllowAny)
- POST /api/usuarios/password-reset/confirmar/ (AllowAny)
- La solicitud busca el email con iexact. Si existe, genera uidb64 + token
  con default_token_generator y envia un correo con ambos datos.
- Si el correo no existe no lanza error y responde el mismo mensaje, para no

- La confirmacion decodifica el UID, valida el token, valida la nueva
  contrasena con los validadores de Django y la guarda con set_password.
- Token invalido/expirado o contrasena debil: 400 con mensaje en espanol.

from django.contrib.auth import password_validation
from django.core.exceptions import ValidationError as DjangoValidationError
from rest_framework import serializers
from rest_framework_simplejwt.serializers import TokenObtainPairSerializer

from .models import User


class RegistroClienteSerializer(serializers.ModelSerializer):
    password = serializers.CharField(write_only=True, min_length=8)
    password_confirmacion = serializers.CharField(write_only=True)

    class Meta:
        model = User
        # rol, is_staff, is_active e is_superuser no se exponen: si el cliente
        # los envía, DRF los ignora y el usuario queda siempre como cliente.
        fields = (
            "email",
            "nombre",
            "apellido",
            "telefono",
            "password",
            "password_confirmacion",
        )

    def validate_email(self, value):
        email = value.strip().lower()
        if User.objects.filter(email__iexact=email).exists():
            raise serializers.ValidationError(
                "Ya existe un usuario registrado con este correo."
            )
        return email

    def validate(self, data):
        password = data.get("password")
        if password != data.pop("password_confirmacion", None):
            raise serializers.ValidationError(
                {"password": "Las contraseñas no coinciden"}
            )

        usuario = User(
            email=data.get("email", ""),
            nombre=data.get("nombre", ""),
            apellido=data.get("apellido", ""),
            telefono=data.get("telefono", ""),
        )
        try:
            password_validation.validate_password(password, usuario)
        except DjangoValidationError as exc:
            raise serializers.ValidationError({"password": list(exc.messages)})

        return data


class LoginSerializer(TokenObtainPairSerializer):
    """Proceso de login:

    1. Recibe "email" y "password".
    2. Normaliza el email (sin espacios y en minúsculas).
    3. TokenObtainPairSerializer valida las credenciales con el backend de
       autenticación de Django. Si el correo no existe, la contraseña es
       incorrecta o el usuario está inactivo, responde 401 con el mismo
       mensaje genérico para no revelar si el correo está registrado.
    4. Genera el par de tokens access/refresh y agrega el rol como claim
       informativo.
    """

    default_error_messages = {
        "no_active_account": "Correo o contraseña incorrectos.",
    }

    # Agrega el claim "rol" al token para que el cliente sepa qué interfaz
    # mostrar. Nota: los permisos NO se deben decidir confiando solo en este
    # claim; el backend siempre debe consultar el usuario autenticado.
    @classmethod
    def get_token(cls, user):
        token = super().get_token(user)
        token["rol"] = user.rol
        return token

    # Normaliza el email antes de autenticar, de modo que el login funcione
    # aunque el cliente lo envíe con mayúsculas o espacios.
    def validate(self, attrs):
        attrs[self.username_field] = attrs[self.username_field].strip().lower()
        return super().validate(attrs)


class UsuarioSerializer(serializers.ModelSerializer):
    class Meta:
        model = User
        fields = ("id", "nombre", "apellido", "email", "telefono", "rol")
        read_only_fields = fields

from rest_framework.views import APIView
from rest_framework.response import Response
from rest_framework import status, permissions

from .serializers import (
    RegistroClienteSerializer,
    LoginSerializer,
    UsuarioSerializer,
)
from .services import registrar_cliente


class RegistroClienteView(APIView):
    permission_classes = [permissions.AllowAny]

    def post(self, request):
        serializer = RegistroClienteSerializer(data=request.data)
        serializer.is_valid(raise_exception=True)

        datos = serializer.validated_data
        usuario = registrar_cliente(**datos)

        return Response(
            {
                "mensaje": "Usuario registrado exitosamente",
                "id": str(usuario.id),
                "email": usuario.email,
            },
            status=status.HTTP_201_CREATED,
        )


class LoginView(APIView):
    """Endpoint de login.

    Recibe email y contraseña, delega la validación a LoginSerializer y
    responde 200 con {"access", "refresh"} o 401 con un mensaje genérico si
    las credenciales no son válidas o el usuario está inactivo.
    """

    permission_classes = [permissions.AllowAny]

    def post(self, request):
        serializer = LoginSerializer(
            data=request.data, context={"request": request}
        )
        serializer.is_valid(raise_exception=True)

        return Response(serializer.validated_data, status=status.HTTP_200_OK)


class MeView(APIView):
    """Datos del usuario autenticado.

    JWTAuthentication valida el Bearer token; si falta o es inválido responde
    401. Si es válido, devuelve id, nombre, apellido, email, teléfono y rol.
    """

    permission_classes = [permissions.IsAuthenticated]

    def get(self, request):
        serializer = UsuarioSerializer(request.user)
        return Response(serializer.data, status=status.HTTP_200_OK)

from rest_framework.test import APITestCase

PASSWORD = "ClaveSegura#2024"


class RegistroClienteTests(APITestCase):
    def setUp(self):
        self.url = reverse("registro_cliente")

    def _payload(self, **overrides):
        data = {
            "email": "nuevo@example.com",
            "nombre": "Ana",
            "apellido": "Gomez",
            "telefono": "3001234567",
            "password": PASSWORD,
            "password_confirmacion": PASSWORD,
        }
        data.update(overrides)
        return data

    def test_registro_exitoso(self):
        response = self.client.post(
            self.url, self._payload(email="  Nuevo@Example.com  "), format="json"
        )

        self.assertEqual(response.status_code, status.HTTP_201_CREATED)
        self.assertNotIn("access", response.data)
        self.assertNotIn("refresh", response.data)

        usuario = User.objects.get(email="nuevo@example.com")
        self.assertEqual(usuario.rol, Rol.CLIENTE)
        self.assertTrue(usuario.is_active)
        self.assertFalse(usuario.is_staff)
        self.assertFalse(usuario.is_superuser)

    def test_email_duplicado_sin_distinguir_mayusculas(self):
        User.objects.create_user(
            email="duplicado@example.com",
            password=PASSWORD,
            nombre="Otro",
            apellido="Cliente",
            telefono="3000000000",
        )

        response = self.client.post(
            self.url, self._payload(email="DUPLICADO@EXAMPLE.COM"), format="json"
        )

        self.assertEqual(response.status_code, status.HTTP_400_BAD_REQUEST)
        self.assertIn("email", response.data)

    def test_contrasenas_no_coinciden(self):
        response = self.client.post(
            self.url,
            self._payload(password_confirmacion="OtraClave#2024"),
            format="json",
        )

        self.assertEqual(response.status_code, status.HTTP_400_BAD_REQUEST)
        self.assertIn("password", response.data)

    def test_contrasena_debil(self):
        response = self.client.post(
            self.url,
            self._payload(password="12345678", password_confirmacion="12345678"),
            format="json",
        )

        self.assertEqual(response.status_code, status.HTTP_400_BAD_REQUEST)
        self.assertIn("password", response.data)

    def test_campos_sensibles_ignorados(self):
        response = self.client.post(

from rest_framework.permissions import BasePermission

from apps.usuarios.models import Rol


class _RolPermitidoBase(BasePermission):
    """Base para permisos por rol.

    Exige usuario autenticado y activo, y que su rol esté en `roles`.
    La decisión se toma SIEMPRE con request.user.rol (el usuario cargado desde
    la base de datos), nunca con el claim "rol" del token JWT.
    """

    message = "No tienes permiso para realizar esta acción."
    roles = frozenset()

    def has_permission(self, request, view):
        usuario = getattr(request, "user", None)
        if usuario is None or not usuario.is_authenticated:
            return False
        if not usuario.is_active:
            return False
        return usuario.rol in self.roles


def RolPermitido(*roles):
    """Fábrica de clases de permiso para uno o varios roles.

    Uso directo: `permission_classes = [RolPermitido(Rol.COCINA, Rol.OPERADOR)]`.
    También se pueden combinar las clases concretas con el operador `|` de DRF.
    """

    return type(
        "RolPermitido",
        (_RolPermitidoBase,),
        {"roles": frozenset(roles)},
    )

ROLES_PERSONAL = (Rol.OPERADOR, Rol.COCINA, Rol.REPARTIDOR, Rol.ADMIN)
ROLES_OPERATIVOS = (Rol.OPERADOR, Rol.COCINA, Rol.REPARTIDOR)


def crear_usuario_personal(
    *,
    email: str,
    password: str,
    nombre: str,
    apellido: str,
    telefono: str,
    rol: str,
    sedes_ids=None,
) -> User:
    with transaction.atomic():
        if rol not in ROLES_PERSONAL:
            raise ValueError(
                "El rol indicado no es válido para registrar personal."
            )

        sedes_ids = list(sedes_ids or [])
        if rol in ROLES_OPERATIVOS and not sedes_ids:
            raise ValueError(
                "Debes asignar al menos una sede para este rol."
            )

        sedes = list(Sede.objects.filter(id__in=sedes_ids, activa=True))
        ids_unicos = {str(sede_id) for sede_id in sedes_ids}
        if sedes_ids and len(sedes) != len(ids_unicos):
            raise ValueError("Una o más sedes no existen o están inactivas.")

        usuario = User.objects.create_user(
            email=email,
            password=password,
            nombre=nombre,
            apellido=apellido,
            telefono=telefono,
            rol=rol,
            is_staff=(rol == Rol.ADMIN),
        )

        SedeUsuario.objects.bulk_create(
            [SedeUsuario(usuario=usuario, sede=sede) for sede in sedes]
        )

        if rol == Rol.REPARTIDOR:
            PerfilRepartidor.objects.create(usuario=usuario, disponible=False)

        return usuario

from django.contrib.auth import password_validation
from django.contrib.auth.tokens import default_token_generator
from django.core.exceptions import ValidationError as DjangoValidationError
from django.core.mail import send_mail
from django.utils.encoding import force_bytes, force_str
from django.utils.http import urlsafe_base64_decode, urlsafe_base64_encode


def solicitar_recuperacion_password(*, email: str) -> None:
    """Genera un token de reset y lo envia por correo si el usuario existe.

    Si el correo no esta registrado no se lanza ninguna excepcion, para no
    revelar que correos estan dados de alta.
    """
    email = email.strip().lower()
    usuario = User.objects.filter(email__iexact=email).first()
    if usuario is None:
        return

    uidb64 = urlsafe_base64_encode(force_bytes(usuario.pk))
    token = default_token_generator.make_token(usuario)

    asunto = "Recuperación de contraseña - DomiPedidosX"
    mensaje = (
        "Recibimos una solicitud para restablecer tu contraseña.\n\n"
        f"uid: {uidb64}\n"
        f"token: {token}\n\n"
        "Si no solicitaste este cambio, ignora este correo."
    )
    send_mail(asunto, mensaje, None, [usuario.email], fail_silently=False)


def confirmar_recuperacion_password(*, uidb64, token, new_password) -> User:
    """Valida el token de recuperacion y actualiza la contrasena del usuario."""
    try:
        uid = force_str(urlsafe_base64_decode(uidb64))
        usuario = User.objects.get(pk=uid)
    except (
        TypeError,
        ValueError,
        OverflowError,
        UnicodeDecodeError,
        DjangoValidationError,
        User.DoesNotExist,
    ):
        raise ValueError("El enlace de recuperación es inválido o expiró.")

    if not default_token_generator.check_token(usuario, token):
        raise ValueError("El enlace de recuperación es inválido o expiró.")

    password_validation.validate_password(new_password, usuario)

    usuario.set_password(new_password)
    usuario.save(update_fields=["password"])
    return usuario


def actualizar_perfil_usuario(
    usuario, *, nombre=None, apellido=None, telefono=None
) -> User:
    """Actualiza unicamente los campos permitidos del perfil del usuario."""
    campos_actualizados = []

    if nombre is not None:
        usuario.nombre = nombre
        campos_actualizados.append("nombre")
    if apellido is not None:
        usuario.apellido = apellido
        campos_actualizados.append("apellido")
    if telefono is not None:
        usuario.telefono = telefono
        campos_actualizados.append("telefono")

    if campos_actualizados:
        usuario.save(update_fields=campos_actualizados)

    return usuario

                {"detail": str(exc)}, status=status.HTTP_400_BAD_REQUEST
            )
        except DjangoValidationError as exc:
            return Response(
                {"new_password": list(exc.messages)},
                status=status.HTTP_400_BAD_REQUEST,
            )

        return Response(
            {"mensaje": "Contraseña actualizada correctamente."},
            status=status.HTTP_200_OK,
        )

def validar_horarios(horarios):
    """Valida coherencia y traslapes de una lista de horarios (dicts)."""
    if not horarios:
        return

    tramos_por_dia = {}
    for horario in horarios:
        dia = horario.get("dia_semana")
        apertura = horario.get("hora_apertura")
        cierre = horario.get("hora_cierre")

        if dia is None or not 1 <= int(dia) <= 7:
            raise ValueError("El día de la semana debe estar entre 1 y 7.")
        if apertura is None or cierre is None:
            raise ValueError(
                "Cada horario debe tener hora de apertura y de cierre."
            )
        if cierre <= apertura:
            raise ValueError(
                "La hora de cierre debe ser mayor que la hora de apertura."
            )

        tramos_por_dia.setdefault(int(dia), []).append((apertura, cierre))

    for tramos in tramos_por_dia.values():
        tramos.sort(key=lambda tramo: tramo[0])
        for anterior, siguiente in zip(tramos, tramos[1:]):
            if siguiente[0] < anterior[1]:
                raise ValueError(
                    "Los horarios de un mismo día no pueden traslaparse."
                )


def crear_sede(*, nombre, direccion, telefono=None, latitud=None,
               longitud=None, horarios=None):
    horarios = horarios or []
    validar_horarios(horarios)

    with transaction.atomic():
        sede = Sede.objects.create(
            nombre=nombre,
            direccion=direccion,
            telefono=telefono or "",
            latitud=latitud,
            longitud=longitud,
        )
        HorarioAtencion.objects.bulk_create(
            [HorarioAtencion(sede=sede, **horario) for horario in horarios]
        )
        return sede


def actualizar_sede(sede, *, datos_sede, horarios=None):
    with transaction.atomic():
        campos_actualizados = {}

        for campo in ("nombre", "direccion", "telefono", "latitud", "longitud"):
            if campo not in datos_sede:
                continue
            valor = datos_sede[campo]
            if campo == "telefono" and valor is None:
                valor = ""
            setattr(sede, campo, valor)
            campos_actualizados[campo] = valor

        if campos_actualizados:
            sede.save(update_fields=list(campos_actualizados))

        if horarios is not None:
            validar_horarios(horarios)
            sede.horarios.all().delete()
            HorarioAtencion.objects.bulk_create(
                [HorarioAtencion(sede=sede, **horario) for horario in horarios]
            )

        return sede


def desactivar_sede(sede):
    """Aplica borrado logico: la sede deja de estar activa, no se elimina."""
    with transaction.atomic():
        sede.activa = False
        sede.save(update_fields=["activa"])
        return sede

class HorarioAtencionSerializer(serializers.ModelSerializer):
    class Meta:
        model = HorarioAtencion
        fields = ("dia_semana", "hora_apertura", "hora_cierre")

    def validate(self, data):
        apertura = data.get("hora_apertura")
        cierre = data.get("hora_cierre")

        if apertura is not None and cierre is not None and cierre <= apertura:
            raise serializers.ValidationError(
                {"hora_cierre": (
                    "La hora de cierre debe ser mayor que la hora de apertura."
                )}
            )
        return data


class SedeSerializer(serializers.ModelSerializer):
    horarios = HorarioAtencionSerializer(many=True, required=False)

    class Meta:
        model = Sede
        fields = (
            "id", "nombre", "direccion", "telefono", "latitud",
            "longitud", "activa", "horarios",
        )
        read_only_fields = ("id", "activa")

    def validate_horarios(self, value):
        try:
            validar_horarios(value)
        except ValueError as exc:
            raise serializers.ValidationError(str(exc))
        return value

  * PUT    /api/sedes/<uuid>/ -> EsAdmin.
  * PATCH  /api/sedes/<uuid>/ -> EsAdmin.
  * DELETE /api/sedes/<uuid>/ -> EsAdmin; activa=False y respuesta 200.

Parametro opcional:
- incluir_inactivas=true (solo surte efecto para un admin autenticado).

Respuestas representativas:
- 201 al crear, 200 al consultar/editar/desactivar.
- 400 con mensaje en espanol ante horarios invalidos o traslapados.
- 401 sin token valido en escritura.
- 403 para roles distintos de admin en escritura.
- 404 si la sede no existe o esta inactiva y el solicitante no es admin.
